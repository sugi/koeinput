# M2: Minimal fcitx5 Addon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An fcitx5 module that lets the user dictate into the focused text field with a push-to-talk hotkey (Right Alt by default), showing status and partial text, and committing the daemon's final text.

**Architecture:** A C++ addon under `addon/`, built with CMake against the fcitx5 development packages. The session logic is a pure class (`Controller`) with no fcitx5 types; `DaemonClient` wraps fcitx5's asynchronous D-Bus library; `KoeInputAddon` is the glue (key watcher, display, timer, settings, notifications). Tests: unit tests of the controller, a D-Bus client test and a headless fcitx5 test against the real M1 daemon built with `test-hooks`.

**Tech Stack:** C++20, CMake ≥ 3.25, fcitx5 5.1.12 (Debian 13) and 5.0.21 (Debian 12, compile check), fcitx5 `dbus`, `notifications`, `testfrontend`, `testim`, `testui` modules, gettext, CPack (DEB). Builds run in rootless podman containers through `scripts/dev`.

**Spec:** `docs/superpowers/specs/2026-10-18-m2-addon-design.md` (read it first). Background: `docs/decisions.md`, `docs/superpowers/specs/2026-10-17-m1-daemon-cli-design.md` (D-Bus interface).

## Global Constraints

- Never copy code from fcitx5-vinput (GPL-3.0). Do not read its source.
- Every build and test runs through `scripts/dev` (Debian 13 image) or `KOEINPUT_DEV_IMAGE=bookworm scripts/dev` (Debian 12 image). Never build on the bare dev container, and never run fcitx5, the addon tests or the daemon tests against the user's session bus: tests always run inside the build container under `dbus-run-session`.
- CPU-heavy commands run under `nice -n 10` (`scripts/dev` does this). Use `-j8` for builds.
- The addon must compile against fcitx5 5.0.21 and 5.1.12. Use only APIs present in both; use `#if` on `FCITX_VERSION_*`-style checks only if unavoidable.
- No synchronous D-Bus call, no polling, no blocking I/O in the addon. The only file I/O is fcitx5's config read/save of `conf/koeinput.conf`. Do not change input context capability flags.
- D-Bus: bus name `org.nemui.KoeInput`, object `/org/nemui/KoeInput`, interface `org.nemui.KoeInput.Recognizer1`; methods `Start(a{sv}) → u`, `Stop(u)`, `Cancel(u)`; signals `StateChanged(u, s)`, `Partial(u, s)`, `Final(u, s)`, `Error(u, s code, s message)`; states `starting`, `recording`, `finalizing`, `done`, `cancelled`, `error`; error names `org.nemui.KoeInput.Error.Busy`, `.NoModel`, `.NoSuchSession`.
- Timeouts: `Start` 5 s, `Stop` and `Cancel` 3 s, no `Final` 10 s after `Stop` → cancel. Repeat gap 1000 ms for non-modifier hotkeys (inclusive); modifier hotkeys never repeat. Buffer at most 64 early signals. Tap threshold default 300 ms, range 100–1000.
- Defaults: hotkey `Alt_R`; tap to keep recording on; show partial results on.
- UI strings are English msgids marked with `_()` and translated in `po/ja.po` (gettext domain `fcitx5-koeinput`). Japanese texts: `準備中…`, `録音中`, `録音中（もう一度押すと確定）`, `認識中…`.
- Recognized text is never logged.
- Addon descriptor: `Category=Module`, `Type=SharedLibrary`, `Library=libkoeinput`, `OnDemand=False`, `Configurable=True`, dependencies `core:5.0.0` and `dbus`, optional dependency `notifications`.
- Local package: `fcitx5-koeinput`, version `0.1.0~dev1`, maintainer `Tatsuki Sugiura <sugi@nemui.org>`.
- Comments: only for non-obvious context. No bare task numbers in comments.
- Commit messages in English, ending with `Co-Authored-By: <the model that wrote the commit> <noreply@anthropic.com>` (for example `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).
- Every shell command starts with `cd <your worktree or the repository> && `. No background processes. No commands that wait on stdin.

## Review Focus

1. A key release that never arrives (some X11 paths) → the next hotkey press still stops the session instead of being treated as auto-repeat forever; a non-modifier hotkey's first auto-repeat (about 600 ms after the press) does not stop a hold. Tests: Task 2 `lost_release_new_press_stops`, `first_repeat_of_plain_key_is_a_repeat`.
2. Signals that arrive before the `Start` reply (the M1 daemon forwards signals before it returns) → nothing is lost, status and partial text show up. Test: Task 2 `signals_before_reply_are_replayed`, Task 3 scenario "signals may precede the reply".
3. The user starts typing right after releasing the hotkey, while the final text is still on its way → the typed key reaches the app, the panel/preedit is released at once, and the dictated text is still committed. Test: Task 2 `other_key_while_finalizing_releases_display`.
4. The daemon is not running or vanishes mid-session → the hotkey press and release are both swallowed (no half key in the app), the session ends, and the next press works once the daemon is back. Test: Task 4 scenario "daemon killed".
5. Mozc (or any engine) is composing → the hotkey goes to the engine untouched. Test: Task 4 scenario "composing passes through".

#!/bin/sh
# Builds, tests or packages the fcitx5 addon in the build container.
# Usage: scripts/addon build|test|deb   (KOEINPUT_DEV_IMAGE=bookworm for the Debian 12 check)
set -eu
root=$(cd "$(dirname "$0")/.." && pwd)
name=${KOEINPUT_DEV_IMAGE:-trixie}
build=target/addon
[ "$name" = trixie ] || build="target/addon-$name"
configure="cmake -S addon -B $build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DCMAKE_INSTALL_PREFIX=/usr"
compile="cmake --build $build -j8"
case "${1:-}" in
  build)
    "$root/scripts/dev" sh -c "$configure && $compile" ;;
  test)
    daemon=
    if [ "$name" = trixie ]; then
      "$root/scripts/dev" cargo build -p koeinput-daemon --features test-hooks
      daemon=/src/target/debug/koeinput-daemon
    fi
    "$root/scripts/dev" sh -c "$configure && $compile && KOEINPUT_TEST_DAEMON=$daemon dbus-run-session -- ctest --test-dir $build --output-on-failure" ;;
  deb)
    "$root/scripts/dev" sh -c "$configure && $compile && cd $build && cpack -G DEB" ;;
  *)
    echo "usage: scripts/addon build|test|deb" >&2
    exit 2 ;;
esac
```

`addon/test/testsupport.h` — shared by `daemonclient_test` (Task 3) and `addon_test`:

```cpp
#pragma once

#include <fcitx-utils/event.h>
#include <cerrno>
#include <csignal>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <functional>
#include <memory>
#include <string>
#include <sys/wait.h>
#include <unistd.h>
#include <utility>
#include <vector>

extern char **environ;

namespace koeinput::test {

inline int failures = 0;

#define KI_CHECK(cond)                                                         \
    do {                                                                       \
        if (!(cond)) {                                                         \
            std::fprintf(stderr, "%s:%d: CHECK failed: %s\n", __FILE__,       \
                         __LINE__, #cond);                                     \
            ++::koeinput::test::failures;                                      \
        }                                                                      \
    } while (0)

// Runs steps one after another on an fcitx5 event loop. Each step waits
// delayMs after the previous one; `done` runs after the last step.
class Steps {
public:
    struct Step {
        uint64_t delayMs;
        std::string name;
        std::function<void()> fn;
    };

    Steps(fcitx::EventLoop &loop, std::function<void()> done)
        : loop_(loop), done_(std::move(done)) {}

    Steps &then(uint64_t delayMs, std::string name, std::function<void()> fn) {
        steps_.push_back({delayMs, std::move(name), std::move(fn)});
        return *this;
    }

    void start() { schedule(0); }

private:
    void schedule(size_t i) {
        if (i == steps_.size()) {
            pending_.reset();
            done_();
            return;
        }
        pending_ = loop_.addTimeEvent(
            CLOCK_MONOTONIC, fcitx::now(CLOCK_MONOTONIC) + steps_[i].delayMs * 1000, 0,
            [this, i](fcitx::EventSourceTime *, uint64_t) {
                std::fprintf(stderr, "step: %s\n", steps_[i].name.c_str());
                steps_[i].fn();
                // Replacing pending_ here would destroy the running event source.
                deferred_ = loop_.addDeferEvent([this, i](fcitx::EventSource *) {
                    schedule(i + 1);
                    return true;
                });
                return true;
            });
    }

    fcitx::EventLoop &loop_;
    std::function<void()> done_;
    std::vector<Step> steps_;
    std::unique_ptr<fcitx::EventSourceTime> pending_;
    std::unique_ptr<fcitx::EventSource> deferred_;
};

// The M1 daemon built with test-hooks, on the private test bus.
class DaemonProcess {
public:
    static const char *binary() {
        const char *b = std::getenv("KOEINPUT_TEST_DAEMON");
        return (b && *b) ? b : nullptr;
    }

    explicit DaemonProcess(std::vector<std::pair<std::string, std::string>> extraEnv = {}) {
        char dirTemplate[] = "/tmp/koeinput-test-XXXXXX";
        dir_ = mkdtemp(dirTemplate);
        std::vector<std::string> env;
        for (char **e = environ; *e; ++e) env.emplace_back(*e);
        env.push_back("HOME=" + dir_);
        env.push_back("XDG_CONFIG_HOME=" + dir_ + "/config");
        env.push_back("XDG_DATA_HOME=" + dir_ + "/data");
        env.push_back("KOEINPUT_TEST_FAKE=1");
        for (auto &[k, v] : extraEnv) env.push_back(k + "=" + v);
        std::vector<char *> envp;
        for (auto &s : env) envp.push_back(s.data());
        envp.push_back(nullptr);
        std::string log = dir_ + "/stderr.log";
        pid_ = fork();
        if (pid_ == 0) {
            FILE *f = std::freopen(log.c_str(), "w", stderr);
            (void)f;
            char *argv[] = {const_cast<char *>(binary()), nullptr};
            execve(argv[0], argv, envp.data());
            _exit(127);
        }
        waitUntilReady();
    }

    ~DaemonProcess() { stop(); }

    void stop() {
        if (pid_ <= 0) return;
        ::kill(pid_, SIGTERM);
        int status = 0;
        waitpid(pid_, &status, 0);
        pid_ = -1;
        // Wait until the bus has released the name, so the next daemon can take it.
        for (int i = 0; i < 100 && ownerPresent(); ++i) usleep(20000);
    }

private:
    static bool ownerPresent() {
        return std::system("dbus-send --session --print-reply --dest=org.freedesktop.DBus "
                           "/org/freedesktop/DBus org.freedesktop.DBus.GetNameOwner "
                           "string:org.nemui.KoeInput >/dev/null 2>&1") == 0;
    }

    void waitUntilReady() {
        const char *cmd =
            "dbus-send --session --print-reply --dest=org.nemui.KoeInput /org/nemui/KoeInput "
            "org.freedesktop.DBus.Properties.Get string:org.nemui.KoeInput.Recognizer1 "
            "string:Ready 2>/dev/null";
        for (int i = 0; i < 200; ++i) {
            if (FILE *p = popen(cmd, "r")) {
                char buf[512];
                std::string out;
                while (std::fgets(buf, sizeof buf, p)) out += buf;
                pclose(p);
                // A model that fails to load (KOEINPUT_TEST_NO_MODEL) never becomes ready.
                if (out.find("boolean true") != std::string::npos ||
                    (out.find("boolean false") != std::string::npos && notReadyOk_)) {
                    return;
                }
            }
            usleep(50000);
        }
        std::fprintf(stderr, "daemon did not become ready; log in %s\n", dir_.c_str());
        std::abort();
    }

public:
    // For a daemon that is expected to stay not ready (no model).
    static DaemonProcess notReady(std::vector<std::pair<std::string, std::string>> extraEnv) {
        notReadyOk_ = true;
        DaemonProcess d(std::move(extraEnv));
        notReadyOk_ = false;
        return d;
    }
    DaemonProcess(DaemonProcess &&o) noexcept : pid_(o.pid_), dir_(std::move(o.dir_)) { o.pid_ = -1; }

private:
    static inline bool notReadyOk_ = false;
    pid_t pid_ = -1;
    std::string dir_;
};

} // namespace koeinput::test
```

`addDeferEvent` exists in fcitx5 5.0 and 5.1 (`fcitx-utils/event.h`); check its exact signature in both images and adjust the lambda if needed. The deferred source must fire only once: if it fires on every loop iteration, call `setOneShot()` on it (check `EventSource` in `event.h`). Leave the temporary directories in `/tmp` of the build container; the container is removed after the run.

```cpp

#include <fcitx-module/testfrontend/testfrontend_public.h>
#include <fcitx-utils/testing.h>
#include <fcitx/addonmanager.h>
#include <fcitx/inputcontextmanager.h>

using namespace fcitx;
using koeinput::test::failures;

int main() {
    setupTestingEnvironment(KOEINPUT_BINARY_DIR, {KOEINPUT_BINARY_DIR, FCITX5_SYSTEM_ADDONDIR},
                            {KOEINPUT_BINARY_DIR "/testdata", FCITX5_SYSTEM_PKGDATADIR "/testing",
                             FCITX5_SYSTEM_PKGDATADIR});
    char arg0[] = "addon_test";
    char arg1[] = "--disable=all";
    char arg2[] = "--enable=testfrontend,testim,testui,dbus,koeinput";
    char *argv[] = {arg0, arg1, arg2};
    Instance instance(3, argv);
    instance.addonManager().registerDefaultLoader(nullptr);

    AddonInstance *frontend = nullptr;
    ICUUID uuid{};
    koeinput::test::Steps steps(instance.eventLoop(), [&] { instance.exit(); });
    steps
        .then(0, "addon loads",
              [&] {
                  KI_CHECK(instance.addonManager().addon("koeinput", true) != nullptr);
                  frontend = instance.addonManager().addon("testfrontend");
                  KI_CHECK(frontend != nullptr);
                  uuid = frontend->call<ITestFrontend::createInputContext>("testapp");
                  auto *ic = instance.inputContextManager().findByUUID(uuid);
                  KI_CHECK(ic != nullptr);
                  ic->focusIn();
              })
        .then(0, "ordinary key passes", [&] {
            KI_CHECK(!frontend->call<ITestFrontend::sendKeyEvent>(uuid, Key("a"), false));
            KI_CHECK(!frontend->call<ITestFrontend::sendKeyEvent>(uuid, Key("a"), true));
        });
    steps.start();
    instance.exec();
    std::fprintf(stderr, "%d failure(s)\n", failures);
    return failures ? 1 : 0;
}

If `testfrontend`'s input context is already focused, the `focusIn()` call is harmless.

#pragma once

#include <cstddef>
#include <cstdint>
#include <optional>
#include <string>
#include <vector>

namespace koeinput {

enum class Status { Preparing, Recording, RecordingTap, Finalizing };

enum class Notice {
    NoDaemon,
    NoModel,
    Busy,
    NoResponse,
    AudioError,
    ModelError,
    InternalError,
    DaemonLeft,
    Failed,
};

enum class CallError { NoDaemon, NoModel, Busy, Timeout, Other };

CallError callErrorFromName(const std::string &dbusErrorName);

struct Settings {
    bool tapToggle = true;
    uint64_t tapThresholdMs = 300;
    bool showPartial = true;
};

class Actions {
public:
    virtual ~Actions() = default;
    virtual void callStart() = 0;
    virtual void callStop(uint32_t id) = 0;
    virtual void callCancel(uint32_t id) = 0;
    virtual void showStatus(Status status) = 0;
    virtual void showPartial(const std::string &text) = 0;
    virtual void clearDisplay() = 0;
    virtual void commit(const std::string &text) = 0;
    virtual void notify(Notice notice, const std::string &detail) = 0;
    virtual void startTimer(uint64_t ms) = 0;
    virtual void stopTimer() = 0;
};

// Session logic of the addon: hotkey handling, the daemon's signals and
// what to display. It knows nothing about fcitx5 or D-Bus.
class Controller {
public:
    static constexpr uint64_t kRepeatGapMs = 500;
    static constexpr uint64_t kFinalizeTimeoutMs = 10000;
    static constexpr std::size_t kMaxBuffered = 64;

    Controller(Actions &actions, Settings settings);

    void setSettings(const Settings &settings) { settings_ = settings; }

    // Key inputs return true when the key must be swallowed.
    bool hotkeyPress(uint64_t nowMs, bool eligible, bool modifier);
    bool hotkeyRelease(uint64_t nowMs);
    bool escape();
    bool otherKeyPress();
    void focusLost();

    void startReply(uint32_t id);
    void startFailed(CallError kind, const std::string &message);
    void stopFailed(uint32_t id, CallError kind, const std::string &message);
    void stateChanged(uint32_t id, const std::string &state);
    void partial(uint32_t id, const std::string &text);
    void finalText(uint32_t id, const std::string &text);
    void error(uint32_t id, const std::string &code, const std::string &message);
    void daemonLeft();
    void timerFired();

    bool idle() const { return phase_ == Phase::Idle; }

private:
    enum class Phase { Idle, Starting, Active, Finalizing };
    enum class SignalKind { State, Partial, Final, Error };
    struct Buffered {
        SignalKind kind;
        uint32_t id;
        std::string a;
        std::string b;
    };

    void begin(uint64_t nowMs);
    void requestStop();
    void cancel();
    void finish();
    void startWatchdog();
    void showRecording();
    void releaseDisplay();
    bool current(uint32_t id) const { return id_ && *id_ == id; }
    void buffer(SignalKind kind, uint32_t id, const std::string &a, const std::string &b = {});
    void notifyCallError(CallError kind, const std::string &message);

    Actions &actions_;
    Settings settings_;
    Phase phase_ = Phase::Idle;
    std::optional<uint32_t> id_;
    bool keyDown_ = false;
    bool ownsPress_ = false;
    bool startPress_ = false;
    uint64_t lastPressMs_ = 0;
    uint64_t pressStartMs_ = 0;
    bool tapMode_ = false;
    bool daemonRecording_ = false;
    bool pendingStop_ = false;
    bool pendingCancel_ = false;
    bool displayReleased_ = false;
    bool timerRunning_ = false;
    std::vector<Buffered> buffered_;
};

} // namespace koeinput

void checkLog(const char *file, int line, const Log &actual, const Log &expected) {
    if (actual == expected) return;

CallError callErrorFromName(const std::string &name) {
    if (name == "org.freedesktop.DBus.Error.ServiceUnknown" ||
        name == "org.freedesktop.DBus.Error.NameHasNoOwner") {
        return CallError::NoDaemon;
    }
    if (name == "org.nemui.KoeInput.Error.NoModel") return CallError::NoModel;
    if (name == "org.nemui.KoeInput.Error.Busy") return CallError::Busy;
    if (name == "org.freedesktop.DBus.Error.NoReply" ||
        name == "org.freedesktop.DBus.Error.Timeout" ||
        name == "org.freedesktop.DBus.Error.TimedOut") {
        return CallError::Timeout;
    }
    return CallError::Other;
}

Controller::Controller(Actions &actions, Settings settings)
    : actions_(actions), settings_(settings) {}

bool Controller::hotkeyPress(uint64_t nowMs, bool eligible) {
    // Modifier keys do not auto-repeat and other keys repeat every few tens of
    // milliseconds, so a long gap means the release was lost on the way.
    const bool repeat = keyDown_ && nowMs - lastPressMs_ < kRepeatGapMs;
    lastPressMs_ = nowMs;
    if (repeat) return ownsPress_;
    keyDown_ = true;
    startPress_ = false;
    switch (phase_) {
    case Phase::Idle:
        ownsPress_ = eligible;
        if (eligible) {
            startPress_ = true;
            begin(nowMs);
        }
        return ownsPress_;
    case Phase::Starting:
    case Phase::Active:
        ownsPress_ = true;
        requestStop();
        return true;
    case Phase::Finalizing:
        ownsPress_ = true;
        return true;
    }
    return false;
}

bool Controller::hotkeyRelease(uint64_t nowMs) {
    if (!keyDown_) return false;
    keyDown_ = false;
    const bool owned = ownsPress_;
    const bool startPress = startPress_;
    ownsPress_ = false;
    startPress_ = false;
    if (!owned) return false;
    const bool running = (phase_ == Phase::Starting && !pendingStop_ && !pendingCancel_) ||
                         phase_ == Phase::Active;
    if (startPress && running && !tapMode_) {
        if (settings_.tapToggle && nowMs - pressStartMs_ < settings_.tapThresholdMs) {
            tapMode_ = true;
            if (phase_ == Phase::Active && daemonRecording_) showRecording();
        } else {
            requestStop();
        }
    }
    return true;
}

bool Controller::escape() {
    if (phase_ == Phase::Idle) return false;
    cancel();
    return true;
}

bool Controller::otherKeyPress() {
    const bool userStopped =
        phase_ == Phase::Finalizing || (phase_ == Phase::Starting && pendingStop_);
    if (userStopped) {
        releaseDisplay();
    } else if (phase_ != Phase::Idle) {
        cancel();
    }
    return false;
}

void Controller::focusLost() { cancel(); }

void Controller::startReply(uint32_t id) {
    if (phase_ != Phase::Starting) {
        actions_.callCancel(id);
        return;
    }
    if (pendingCancel_) {
        actions_.callCancel(id);
        finish();
        return;
    }
    phase_ = Phase::Active;
    id_ = id;
    auto pending = std::move(buffered_);
    buffered_.clear();
    for (const auto &b : pending) {
        if (phase_ == Phase::Idle) break;
        switch (b.kind) {
        case SignalKind::State: stateChanged(b.id, b.a); break;
        case SignalKind::Partial: partial(b.id, b.a); break;
        case SignalKind::Final: finalText(b.id, b.a); break;
        case SignalKind::Error: error(b.id, b.a, b.b); break;
        }
    }
    if (phase_ == Phase::Active && pendingStop_) {
        pendingStop_ = false;
        requestStop();
    }
}

void Controller::startFailed(CallError kind, const std::string &message) {
    if (phase_ != Phase::Starting) return;
    const bool quiet = pendingCancel_;
    finish();
    if (!quiet) notifyCallError(kind, message);
}

void Controller::stopFailed(uint32_t id, CallError kind, const std::string &message) {
    if (phase_ != Phase::Finalizing || !current(id)) return;
    finish();
    notifyCallError(kind, message);
}

void Controller::stateChanged(uint32_t id, const std::string &state) {
    if (phase_ == Phase::Starting) {
        buffer(SignalKind::State, id, state);
        return;
    }
    if (!current(id)) return;
    if (state == "recording") {
        daemonRecording_ = true;
        if (phase_ == Phase::Active) showRecording();
    } else if (state == "finalizing") {
        if (phase_ == Phase::Active) {
            phase_ = Phase::Finalizing;
            if (!displayReleased_) actions_.showStatus(Status::Finalizing);
            startWatchdog();
        }
    } else if (state == "done" || state == "cancelled" || state == "error") {
        finish();
    }
}

void Controller::partial(uint32_t id, const std::string &text) {
    if (phase_ == Phase::Starting) {
        buffer(SignalKind::Partial, id, text);
        return;
    }
    if (!current(id) || !settings_.showPartial || displayReleased_) return;
    actions_.showPartial(text);
}

void Controller::finalText(uint32_t id, const std::string &text) {
    if (phase_ == Phase::Starting) {
        buffer(SignalKind::Final, id, text);
        return;
    }
    if (!current(id)) return;
    finish();
    if (!text.empty()) actions_.commit(text);
}

void Controller::error(uint32_t id, const std::string &code, const std::string &message) {
    if (phase_ == Phase::Starting) {
        buffer(SignalKind::Error, id, code, message);
        return;
    }
    if (!current(id)) return;
    finish();
    const Notice n = code == "audio"   ? Notice::AudioError
                     : code == "model" ? Notice::ModelError
                                       : Notice::InternalError;
    actions_.notify(n, message);
}

void Controller::daemonLeft() {
    if (phase_ == Phase::Idle) return;
    const bool quiet = pendingCancel_;
    finish();
    if (!quiet) actions_.notify(Notice::DaemonLeft, "");
}

void Controller::timerFired() {
    timerRunning_ = false;
    if (phase_ != Phase::Finalizing) return;
    actions_.callCancel(*id_);
    finish();
    actions_.notify(Notice::NoResponse, "");
}

void Controller::begin(uint64_t nowMs) {
    phase_ = Phase::Starting;
    id_.reset();
    pressStartMs_ = nowMs;
    tapMode_ = false;
    daemonRecording_ = false;
    pendingStop_ = false;
    pendingCancel_ = false;
    displayReleased_ = false;
    buffered_.clear();
    actions_.showStatus(Status::Preparing);
    actions_.callStart();
}

void Controller::requestStop() {
    if (phase_ == Phase::Starting) {
        if (!pendingCancel_) pendingStop_ = true;
        return;
    }
    if (phase_ != Phase::Active) return;
    phase_ = Phase::Finalizing;
    actions_.callStop(*id_);
    if (!displayReleased_) actions_.showStatus(Status::Finalizing);
    startWatchdog();
}

void Controller::cancel() {
    switch (phase_) {
    case Phase::Idle:
        return;
    case Phase::Starting:
        if (!pendingCancel_) {
            pendingCancel_ = true;
            pendingStop_ = false;
            releaseDisplay();
        }
        return;
    case Phase::Active:
    case Phase::Finalizing:
        actions_.callCancel(*id_);
        finish();
        return;
    }
}

void Controller::finish() {
    if (timerRunning_) {
        actions_.stopTimer();
        timerRunning_ = false;
    }
    if (!displayReleased_) actions_.clearDisplay();
    phase_ = Phase::Idle;
    id_.reset();
    tapMode_ = false;
    daemonRecording_ = false;
    pendingStop_ = false;
    pendingCancel_ = false;
    displayReleased_ = false;
    buffered_.clear();
}

void Controller::startWatchdog() {
    actions_.startTimer(kFinalizeTimeoutMs);
    timerRunning_ = true;
}

void Controller::showRecording() {
    if (!displayReleased_) actions_.showStatus(tapMode_ ? Status::RecordingTap : Status::Recording);
}

void Controller::releaseDisplay() {
    if (displayReleased_) return;
    actions_.clearDisplay();
    displayReleased_ = true;
}

void Controller::buffer(SignalKind kind, uint32_t id, const std::string &a, const std::string &b) {
    if (buffered_.size() < kMaxBuffered) buffered_.push_back({kind, id, a, b});
}

void Controller::notifyCallError(CallError kind, const std::string &message) {
    switch (kind) {
    case CallError::NoDaemon: actions_.notify(Notice::NoDaemon, ""); return;
    case CallError::NoModel: actions_.notify(Notice::NoModel, message); return;
    case CallError::Busy: actions_.notify(Notice::Busy, ""); return;
    case CallError::Timeout: actions_.notify(Notice::NoResponse, ""); return;
    case CallError::Other: actions_.notify(Notice::Failed, message); return;
    }
}

#include "daemonclient.h"
#include <fcitx-utils/dbus/matchrule.h>
#include <fcitx-utils/dbus/message.h>
#include <fcitx-utils/dbus/variant.h>
#include <utility>
#include <vector>

namespace koeinput {

using fcitx::dbus::Message;

DaemonClient::DaemonClient(fcitx::dbus::Bus &bus, DaemonCallbacks callbacks)
    : bus_(bus), cb_(std::move(callbacks)), watcher_(bus) {
    watch_ = watcher_.watchService(
        kBusName, [this](const std::string &, const std::string &oldOwner,
                         const std::string &newOwner) {
            if (!oldOwner.empty() && newOwner.empty()) cb_.daemonLeft();
        });
    match_ = bus_.addMatch(fcitx::dbus::MatchRule(kBusName, kObjectPath, kInterface),
                           [this](Message &message) { return onSignal(message); });
}

DaemonClient::~DaemonClient() = default;

Message DaemonClient::methodCall(const char *method) {
    return bus_.createMethodCall(kBusName, kObjectPath, kInterface, method);
}

void DaemonClient::start() {
    auto message = methodCall("Start");
    message << std::vector<fcitx::dbus::DictEntry<std::string, fcitx::dbus::Variant>>();
    startCall_ = message.callAsync(kStartTimeoutUsec, [this](Message &reply) {
        if (reply.isError()) {
            cb_.startFailed(callErrorFromName(reply.errorName()), reply.errorMessage());
            return true;
        }
        uint32_t id = 0;
        reply >> id;
        if (!reply) {
            cb_.startFailed(CallError::Other, "unexpected reply to Start");
            return true;
        }
        cb_.started(id);
        return true;
    });
}

void DaemonClient::stop(uint32_t id) {
    auto message = methodCall("Stop");
    message << id;
    stopCall_ = message.callAsync(kCallTimeoutUsec, [this, id](Message &reply) {
        if (reply.isError()) {
            cb_.stopFailed(id, callErrorFromName(reply.errorName()), reply.errorMessage());
        }
        return true;
    });
}

void DaemonClient::cancel(uint32_t id) {
    auto message = methodCall("Cancel");
    message << id;
    cancelCall_ = message.callAsync(kCallTimeoutUsec, [](Message &) { return true; });
}

bool DaemonClient::onSignal(Message &message) {
    if (message.type() != fcitx::dbus::MessageType::Signal) return false;
    const std::string member = message.member();
    uint32_t id = 0;
    std::string a;
    if (member == "StateChanged") {
        message >> id >> a;
        if (message) cb_.stateChanged(id, a);
    } else if (member == "Partial") {
        message >> id >> a;
        if (message) cb_.partial(id, a);
    } else if (member == "Final") {
        message >> id >> a;
        if (message) cb_.finalText(id, a);
    } else if (member == "Error") {
        std::string b;
        message >> id >> a >> b;
        if (message) cb_.error(id, a, b);
    }
    return true;
}

} // namespace koeinput

```cpp
#include "koeinput.h"
#include <fcitx-config/iniparser.h>
#include <fcitx-module/dbus/dbus_public.h>
#include <fcitx-module/notifications/notifications_public.h>
#include <fcitx-utils/capabilityflags.h>

#include <fcitx/candidatelist.h>
#include <fcitx/inputpanel.h>
#include <fcitx/text.h>
#include <fcitx/userinterface.h>

namespace koeinput {

namespace {

FCITX_DEFINE_LOG_CATEGORY(koeinput_log, "koeinput");
#define KOEINPUT_WARN() FCITX_LOGC(koeinput_log, Warn)

constexpr char kConfPath[] = "conf/koeinput.conf";

std::string statusText(Status status) {
    switch (status) {
    case Status::Preparing: return _("Preparing…");
    case Status::Recording: return _("Recording");
    case Status::RecordingTap: return _("Recording (press again to finish)");
    case Status::Finalizing: return _("Recognizing…");
    }
    return {};
}

std::string withDetail(const char *text, const std::string &detail) {
    return detail.empty() ? std::string(text) : std::string(text) + "\n" + detail;
}

std::string noticeText(Notice notice, const std::string &detail) {
    switch (notice) {
    case Notice::NoDaemon: return _("The KoeInput daemon is not running.");
    case Notice::NoModel: return withDetail(_("The speech model is not ready."), detail);
    case Notice::Busy: return _("Another dictation is running.");
    case Notice::NoResponse: return _("The KoeInput daemon does not respond.");
    case Notice::AudioError: return withDetail(_("Cannot record from the microphone."), detail);
    case Notice::ModelError: return withDetail(_("Speech recognition failed."), detail);
    case Notice::InternalError: return withDetail(_("The KoeInput daemon reported an error."), detail);
    case Notice::DaemonLeft: return _("The KoeInput daemon stopped.");
    case Notice::Failed: return withDetail(_("Dictation failed."), detail);
    }
    return {};
}

uint64_t nowMs() { return fcitx::now(CLOCK_MONOTONIC) / 1000; }

} // namespace

KoeInputAddon::KoeInputAddon(fcitx::Instance *instance)
    : instance_(instance), controller_(*this, Settings{}) {
    reloadConfig();
    if (auto *dbusAddon = dbus()) {
        auto *bus = dbusAddon->call<fcitx::IDBusModule::bus>();
        DaemonCallbacks cb;
        cb.started = [this](uint32_t id) { controller_.startReply(id); };
        cb.startFailed = [this](CallError k, const std::string &m) { controller_.startFailed(k, m); };
        cb.stopFailed = [this](uint32_t id, CallError k, const std::string &m) {
            controller_.stopFailed(id, k, m);
        };
        cb.stateChanged = [this](uint32_t id, const std::string &s) { controller_.stateChanged(id, s); };
        cb.partial = [this](uint32_t id, const std::string &t) { controller_.partial(id, t); };
        cb.finalText = [this](uint32_t id, const std::string &t) { controller_.finalText(id, t); };
        cb.error = [this](uint32_t id, const std::string &c, const std::string &m) {
            controller_.error(id, c, m);
        };
        cb.daemonLeft = [this] { controller_.daemonLeft(); };
        client_ = std::make_unique<DaemonClient>(*bus, std::move(cb));
    }
    watchers_.emplace_back(instance_->watchEvent(
        fcitx::EventType::InputContextKeyEvent, fcitx::EventWatcherPhase::PreInputMethod,
        [this](fcitx::Event &event) { handleKey(static_cast<fcitx::KeyEvent &>(event)); }));
    watchers_.emplace_back(instance_->watchEvent(
        fcitx::EventType::InputContextFocusOut, fcitx::EventWatcherPhase::Default,
        [this](fcitx::Event &event) {
            auto &e = static_cast<fcitx::InputContextEvent &>(event);
            if (e.inputContext() == sessionIc_.get()) controller_.focusLost();
        }));
    watchers_.emplace_back(instance_->watchEvent(
        fcitx::EventType::InputContextDestroyed, fcitx::EventWatcherPhase::Default,
        [this](fcitx::Event &event) {
            auto &e = static_cast<fcitx::InputContextEvent &>(event);
            if (e.inputContext() == pressIc_) pressIc_ = nullptr;
            if (e.inputContext() == sessionIc_.get()) {
                // The context is going away: drop it before the controller clears the display.
                sessionIc_.unwatch();
                controller_.focusLost();
            }
        }));
}

KoeInputAddon::~KoeInputAddon() = default;

void KoeInputAddon::reloadConfig() {
    fcitx::readAsIni(config_, kConfPath);
    applyConfig();
}

void KoeInputAddon::setConfig(const fcitx::RawConfig &config) {
    config_.load(config, true);
    fcitx::safeSaveAsIni(config_, kConfPath);
    applyConfig();
}

void KoeInputAddon::applyConfig() {
    controller_.setSettings(Settings{*config_.tapToggle,
                                     static_cast<uint64_t>(*config_.tapThreshold),
                                     *config_.showPartial});
}

bool KoeInputAddon::eligible(fcitx::InputContext *ic) const {
    if (!client_ || !ic || !ic->hasFocus()) return false;
    if (ic->capabilityFlags().test(fcitx::CapabilityFlag::Password)) return false;
    const auto &panel = ic->inputPanel();
    if (!panel.preedit().empty() || !panel.clientPreedit().empty()) return false;
    const auto list = panel.candidateList();
    return !list || list->size() == 0;
}

void KoeInputAddon::handleKey(fcitx::KeyEvent &event) {
    const auto &key = event.key();
    bool swallow = false;
    if (key.checkKeyList(*config_.hotkey)) {
        if (event.isRelease()) {
            swallow = controller_.hotkeyRelease(nowMs());
        } else {
            pressIc_ = event.inputContext();
            swallow = controller_.hotkeyPress(nowMs(), eligible(pressIc_), key.isModifier());
        }
    } else if (!event.isRelease()) {
        swallow = key.sym() == FcitxKey_Escape ? controller_.escape() : controller_.otherKeyPress();
    }
    if (swallow) event.filterAndAccept();
}

void KoeInputAddon::callStart() {
    sessionIc_ = pressIc_ ? pressIc_->watch() : fcitx::TrackableObjectReference<fcitx::InputContext>();
    client_->start();
}

void KoeInputAddon::callStop(uint32_t id) { client_->stop(id); }

void KoeInputAddon::callCancel(uint32_t id) { client_->cancel(id); }

void KoeInputAddon::showStatus(Status status) {
    auto *ic = sessionIc_.get();
    if (!ic) return;
    ic->inputPanel().setAuxUp(fcitx::Text(statusText(status)));
    ic->updateUserInterface(fcitx::UserInterfaceComponent::InputPanel);
}

void KoeInputAddon::showPartial(const std::string &text) {
    auto *ic = sessionIc_.get();
    if (!ic) return;
    if (ic->capabilityFlags().test(fcitx::CapabilityFlag::Preedit)) {
        ic->inputPanel().setClientPreedit(fcitx::Text(text, fcitx::TextFormatFlag::Underline));
        ic->updatePreedit();
    } else {
        ic->inputPanel().setPreedit(fcitx::Text(text));
    }
    ic->updateUserInterface(fcitx::UserInterfaceComponent::InputPanel);
}

void KoeInputAddon::clearDisplay() {
    auto *ic = sessionIc_.get();
    if (!ic) return;
    auto &panel = ic->inputPanel();
    panel.setAuxUp(fcitx::Text());
    panel.setPreedit(fcitx::Text());
    panel.setClientPreedit(fcitx::Text());
    ic->updatePreedit();
    ic->updateUserInterface(fcitx::UserInterfaceComponent::InputPanel);
}

void KoeInputAddon::commit(const std::string &text) {
    if (auto *ic = sessionIc_.get()) ic->commitString(text);
}

void KoeInputAddon::notify(Notice notice, const std::string &detail) {
    const std::string body = noticeText(notice, detail);
    KOEINPUT_WARN() << body;
    auto *n = notifications();
    if (!n) return;
    notificationId_ = n->call<fcitx::INotifications::sendNotification>(
        "fcitx5-koeinput", notificationId_, "audio-input-microphone", _("KoeInput"), body,
        std::vector<std::string>{}, 5000, nullptr, nullptr);
}

void KoeInputAddon::startTimer(uint64_t ms) {
    timer_ = instance_->eventLoop().addTimeEvent(
        CLOCK_MONOTONIC, fcitx::now(CLOCK_MONOTONIC) + ms * 1000, 0,
        [this](fcitx::EventSourceTime *, uint64_t) {
            controller_.timerFired();
            return true;
        });
}

void KoeInputAddon::stopTimer() { timer_.reset(); }

class KoeInputFactory : public fcitx::AddonFactory {
public:
    fcitx::AddonInstance *create(fcitx::AddonManager *manager) override {
        fcitx::registerDomain(FCITX_GETTEXT_DOMAIN, FCITX_INSTALL_LOCALEDIR);
        return new KoeInputAddon(manager->instance());
    }
};

} // namespace koeinput

FCITX_ADDON_FACTORY(koeinput::KoeInputFactory);
